# Tools examples

The runnable examples in this folder are standalone study scripts. Review each script before running it; some connect to external services or inspect network hosts.

Install the Python package dependencies with:

```bash
python3 -m pip install -r Tools/requirements.txt
```

`active_info.py` also needs the Nmap executable installed on the computer. Only scan systems you own or have permission to assess. The old keylogging, phishing, password-guessing, and remote-command-execution placeholders were moved to `archive/disabled-security-placeholders/` and are not runnable tools.
