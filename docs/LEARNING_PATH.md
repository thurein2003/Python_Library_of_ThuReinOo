# Project2Certificate learning path

The site orders its 20 lessons by the concepts they build on. The size filter still lets learners choose shorter or larger projects within each stage.

## 1. Foundations

1. Tip calculator — numbers, formatting, and input
2. Number challenge — conditions, loops, and state
3. Word counter — strings, lists, and dictionaries
4. Mini quiz — functions and collections

## 2. Functions and data

5. Expense tracker — functions and aggregation
6. Gradebook report — validation and summaries

## 3. Files and structured data

7. Study journal file — paths and text files
8. JSON contact book — JSON records and lookup
9. API response analyzer — validate a representative JSON response
10. CSV sales report — tabular data and totals
11. Debug empty scores — tracebacks and edge cases

The API lesson uses a local example response, so it is repeatable and does not need a live service or an API key.

## 4. Applications

12. Library catalog — classes and object state
13. Command-line task manager — `argparse` commands and task state
14. Text adventure — branching and world state
15. Study planner — scheduling and composed functions
16. Budget dashboard — reporting and comparisons
17. Inventory system — class rules and validation
18. SQLite reading list — SQL queries and an in-memory database

### Expected checkpoints for the new application projects

- The API response solution reports two tasks, with one complete.
- The command-line solution marks the first task complete and leaves the second open.
- The SQLite solution reports `SQL Notes` as unread and 120 unread pages.

The SQLite lesson keeps its data in memory for the current run. It teaches database operations without creating files or claiming to save progress across runs.

## 5. Testing and capstone

19. Test an expense helper — `unittest` and boundary cases
20. Your capstone blueprint — plan a project, implement a first milestone, and test it

Learners can revisit earlier projects at any time. Completion and certificates remain self-reported in the current browser profile.
