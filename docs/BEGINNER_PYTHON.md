# Beginner Python

This Academy track teaches Python fundamentals before learners move on to the larger projects in [Project2Certificate](LEARNING_PATH.md). Every lesson is beginner level and runs in the browser.

## 1. Python foundations

1. Your first Python program — `print()` and output
2. Save information in variables — names, values, and strings
3. Use numbers and simple math — addition, subtraction, and multiplication
4. Work with words — strings, f-strings, and `len()`

## 2. Choices and collections

5. Make a choice with `if` — comparisons and `else`
6. Keep a list of items — list values and `append()`
7. Repeat steps with a loop — `for` and `in`

## 3. Reusable code and practice

8. Make a reusable function — `def`, parameters, and calls
9. Label values with a dictionary — keys and values
10. Mini project: a study plan — combine the beginner concepts

The beginner track uses separate saved progress and does not affect the Project2Certificate completion certificate.
